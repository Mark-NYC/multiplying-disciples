# CONTENT_GRAPH.md

The site's content graph as of the 2026-07 internal-linking audit:
every topic cluster traced **Pillar → Supporting Articles → Tools →
Labs → Community**. ★ = exists · ☆ = planned (see
CONTENT_CLUSTER_ROADMAP.md) · (I) = exists, marked Improve.

The one journey every cluster feeds:

```
Meet Jesus → Share the Gospel → Make Disciples → Train Disciple Makers
          → Practice Church → Multiply Leaders → Multiply Churches
                                      ↓
                              Community (CoVo)
```

Link-mechanics legend: pillar↔support links are `related_articles` +
in-body; tools are terminal pages (link back to their teaching
article only); every editorial article ends in exactly one CTA
(default = Lab; see CTA_GUIDE.md).
