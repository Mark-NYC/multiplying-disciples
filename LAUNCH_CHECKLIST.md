# Launch Checklist

> **DO NOT LAUNCH.** This checklist exists to gate a future launch
> decision. As of Phase 1, most items below are unmet by design — this
> phase only builds the foundation and a small placeholder batch.

Launch means: DNS/hosting cutover so `multiplyingdisciples.us` serves
this Astro site instead of WordPress. That is explicitly out of scope
until every item below is checked and a human has signed off.

## Required before any launch

- [ ] Full Search Console page export obtained (last 3+ months, all
      ~179+ pages with data).
- [ ] Complete protected URL inventory built from that export (extends
      `PROTECTED_URLS.md` / `URL_INVENTORY.md` beyond the current 45
      known URLs).
- [ ] Every URL in the live `sitemap.xml` crawled and accounted for in
      `URL_INVENTORY.md`.
- [ ] Every old URL either recreated in Astro at the exact same path, or
      has a verified 301 in `REDIRECTS.md` — zero `pending` rows.
- [ ] All media URLs in `MEDIA_URLS_TO_PRESERVE.md` preserved (files
      physically present at their original paths) or redirected.
- [x] Sitemap generated by `@astrojs/sitemap` reviewed (Phase 8) —
      `sitemap-0.xml` contains exactly 93 `<loc>` entries, all on
      `https://multiplyingdisciples.us/...`, matching the real
      canonical domain; no placeholder pages included (count matches
      the build exactly).
- [ ] 404 test: spot-check a sample of old URLs post-build; nothing
      that should exist returns 404. (Requires a live/preview
      deployment — not yet done. Note: 6 confirmed real URLs
      currently linked from existing content — `/3-circles/`,
      `/free-training/`, `/4-1-1/`, `/4-fields/`,
      `/movement-resources/strategy-coordinator/`,
      `/movement-resources/4-fields-toolbox/` — are expected to 404
      today since they are not yet migrated; see
      `PHASE_8_FULL_SITE_AUDIT.md` §5.)
- [x] Canonical test (Phase 8): every one of the 93 generated pages'
      `<link rel="canonical">` matches its own served URL path — 0
      mismatches, scripted check across the full `dist/` output.
- [x] `robots.txt` test (Phase 8): `public/robots.txt` allows all
      crawling and correctly points to
      `https://multiplyingdisciples.us/sitemap-index.xml` — matches
      the real sitemap.
- [ ] Internal link crawl (Phase 8 — see `PHASE_8_FULL_SITE_AUDIT.md`
      §5): crawled all 93 pages. 0 empty `href=""`, 0 broken `#`
      anchors, 0 `javascript:` links, all header/footer nav links
      resolve. 33 links point to 6 real, confirmed, not-yet-migrated
      URLs (documented, intentional — not guessed slugs) that will
      404 until those pages are migrated. Leaving this box unchecked
      until those 6 target URLs are either migrated or the links are
      converted to plain text — see "Remaining risks" in
      `PHASE_8_FULL_SITE_AUDIT.md`.
- [ ] Lighthouse / basic speed check run on key templates (homepage,
      article, hub, tool).
- [ ] `ROLLBACK_PLAN.md` reviewed and confirmed workable by whoever
      controls DNS/hosting.
- [ ] Explicit human go/no-go sign-off. Claude Code should not initiate
      a DNS or hosting cutover on its own authority.
